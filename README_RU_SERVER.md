# Руководство по развертыванию Layndaru на сервере в РФ (Москва)

Данный архив содержит полный стек сервисов для работы на российском сервере:
1. **PostgreSQL 16** — локальная база данных с предзаполненными комнатами, машинами, учетными записями и структурой.
2. **Веб-панель управления (`webpanel.local`)** — Apache + PHP 8.2 (интерфейс администратора, управление записями, машинами, жильцами, отправка push-уведомлений во все боты).
3. **MAX-бот (`maxbot`)** — бот для мессенджера MAX (`max.ru`).
4. **VK-бот (`vkbot`)** — бот для социальной сети ВКонтакте.

---

## 1. Быстрый запуск через Docker Compose (Рекомендуется)

На сервере должен быть установлен **Docker** и **Docker Compose** (`sudo apt install docker.io docker-compose-plugin`).

1. Создайте файл `.env` из примера:
   ```bash
   cp .env.example .env
   ```
2. Откройте `.env` и задайте надежный пароль базы данных `DB_PASS`, а также токены `VK_TOKEN`, `VK_GROUP_ID` и `MAX_TOKEN`:
   ```bash
   nano .env
   ```
3. Запустите весь комплекс сервисов:
   ```bash
   docker compose up -d --build
   ```

После запуска:
- **Веб-панель**: доступна по адресу `http://<IP_СЕРВЕРА>:8080` (логин: `admin`, пароль: `admin123`).
- **PostgreSQL**: доступна на порту `5432`.
- **MAX-бот**: автоматически подключен к базе данных и запущен в фоне.
- **VK-бот**: автоматически подключен к базе данных и запущен в фоне.

## 2. Настройка подключения зарубежного Telegram-бота к базе данных

Telegram-бот (`tgbot`) запускается на зарубежном сервере, чтобы беспрепятственно общаться с серверами Telegram.
Он подключается к вашей базе данных PostgreSQL на российском сервере по сети TCP (порт 5432).

### Настройка безопасности на российском сервере (UFW Firewall):
Чтобы защитить базу данных от сканеров и ботов из интернета, **разрешите доступ к порту 5432 только с IP-адреса зарубежного сервера**:

```bash
# Разрешить подключение к PostgreSQL только с IP вашего зарубежного сервера:
sudo ufw allow from <IP_ЗАРУБЕЖНОГО_СЕРВЕРА> to any port 5432 proto tcp

# Разрешить доступ к веб-панели (порт 8080):
sudo ufw allow 8080/tcp

# Разрешить SSH:
sudo ufw allow 22/tcp

# Включить файрвол (если ещё не включен):
sudo ufw enable
```

### Данные для настройки `.env` в Telegram-боте на зарубежном сервере:
В `tgbot/.env` укажите:
```env
HOST=<ПУБЛИЧНЫЙ_IP_РОССИЙСКОГО_СЕРВЕРА>
PORT=5432
USER=postgres
PASSWORD=<ТОТ_ЖЕ_ПАРОЛЬ_ЧТО_В_DB_PASS>
DBNAME=layndaru_db
DATABASE_URL=postgresql+asyncpg://postgres:<ТОТ_ЖЕ_ПАРОЛЬ_ЧТО_В_DB_PASS>@<ПУБЛИЧНЫЙ_IP_РОССИЙСКОГО_СЕРВЕРА>:5432/layndaru_db
```

## 3. Полезные команды

- Проверить статус всех контейнеров:
  ```bash
  docker compose ps
  ```
- Посмотреть логи веб-панели или ботов:
  ```bash
  docker compose logs -f webpanel
  docker compose logs -f maxbot
  docker compose logs -f vkbot
  docker compose logs -f postgres
  ```
- Перезапустить конкретный сервис (например, бота после смены токена):
  ```bash
  docker compose restart maxbot
  ```
- Остановить всё:
  ```bash
  docker compose down
  ```
- Создать резервную копию базы данных:
  ```bash
  docker exec -t layndaru-postgres pg_dump -U postgres layndaru_db > backup_$(date +%F).sql
  ```
