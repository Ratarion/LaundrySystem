# Бот для мессенджера MAX (max.ru / VK MAX)

Автономный бот записи в прачечную общежития для национального мессенджера **MAX** (`max.ru`), собранный на основе логики VK-бота с использованием асинхронного фреймворка `aiomax` и SQLAlchemy 2.0.

---

## 1. Возможности бота
- **Авторизация**: по номеру студенческой карты (`idcards`) или ФИО с автоматической привязкой `max_id`.
- **Выбор техники**: раздельное бронирование стиральных и сушильных машин.
- **Интерактивный календарь**: выбор даты с цветной индикацией доступности слотов (🟢 свободно, 🟡 частично, 🔴 занято, ⚪ недоступно) и пагинацией по неделям.
- **Выбор временных интервалов**: по 90 минут в диапазоне с 8:00 до 23:00 с постраничной навигацией.
- **Лимит**: строго не более 1 активной брони в неделю на один тип машины.
- **Мои записи**: просмотр текущих броней со статусами.
- **Отмена записей**: быстрая отмена и мгновенная рассылка уведомления жителям об освободившемся месте (`broadcaster.py`).
- **Подтверждение визита**: за 20 минут до начала брони бот присылает кнопку «✅ Я приду».
- **Автоотмена**: если бронь не подтверждена за 15 минут до старта, она автоматически аннулируется, освобождая слот другим студентам.
- **Обратная связь**: отправка жалоб и сообщений о поломках администрации в раздел уведомлений панели.
- **Мультиязычность**: Русский (RU), English (ENG), 中文 (CN).

---

## 2. Регистрация бота в мессенджере MAX
1. Откройте мессенджер MAX и найдите официального бота управления **@MasterBot** (`max.ru/masterbot`).
2. Создайте нового бота командой `/newbot`.
3. Задайте имя и юзернейм бота, скопируйте выданный `API Token`.
4. Вставьте токен в файл `.env` в параметр `MAX_TOKEN`.

---

## 3. Установка и запуск

### Шаг 1: Установка зависимостей
```bash
pip install -r requirements.txt
```

### Шаг 2: Настройка `.env`
Скопируйте `.env.example` в `.env`:
```env
MAX_TOKEN=ВАШ_ТОКЕН_ИЗ_MASTERBOT
DATABASE_URL=postgresql+asyncpg://postgres:postgres@localhost:5432/layndaru_db
```

### Шаг 3: Запуск бота
```bash
python main.py
```
